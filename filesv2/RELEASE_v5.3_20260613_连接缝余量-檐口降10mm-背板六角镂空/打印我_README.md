# 墙面种植单元 — 发布版 v5.3

- **版本**:v5.3
- **日期**:2026-06-13
- **打印机**:拓竹 P2S(≤240mm/轴)
- **本版更新(第二轮反馈)**:
  1. **连接缝余量**:连接筒止位环坐进的井口沉孔比环深 **1.0mm**(原 0.6)→ 上下单元叠合面贴死,环顶绝不顶开缝(`conn_recess`)。
  2. **檐口下降 10mm**:`mouth_ext` 16→6 → 容器口沿盆轴下降 10mm(≈竖直 7.4mm),收口贴近真盆口;整机高 228.5→**221.1mm**(仍 ≤240)。
  3. **背板六角镂空减料**(`back_lattice`,默认开):背面 openwork **六角蜂窝窗**栅格皮 + 其后楔形掏空腔(深 30mm)。只动背面、只在储水腔以上;**盆腔壁/落水管/储水盒/前壳/边框/堆叠孔凸台全保留**。省 **≈340cc(21.6% 体积;12% 填充实际≈84g + 墙皮/打印时间)**。贴墙隐藏,经背面孔通外 → 无封闭空腔。

> 安全自检全过:`potcheck`(真盆装得下)、`shaftcheck`、`tilecheck`、`rescheck`、**`latticecheck`(掏空腔×储水盒/落水管)**、**`latticepot`(掏空腔×盆腔)** 均空 → 背面减料不破储水盒/落水管/盆腔。Volumes=2、Simple=yes(单一连通流形)。

## 怎么打
- **单元:盆口朝下贴板**(盆轴竖直、整体后仰约 50°),储水腔/落水井免支撑。
- **背面六角镂空**:贴墙隐藏,纯减料/减重。掏空腔靠 Ø18 级背孔通外,切片若提示腔内少量支撑,可用树状支撑,或把 `lat_ydepth` 调浅、甚至 `back_lattice=false` 恢复实心。
- **储水区加厚**:储水腔那段(沿打印 Z 最低 ~35mm)墙加到 4、填充 15% 防渗;其余 2 周 + 6–8% gyroid。
- **连接筒/插销**:精度优先(层高 0.12–0.16,全实心);连接筒竖放打。
- **底座**:掏空面朝下,免支撑。

## 怎么装 / 浇水
与 v5.2 相同:连接筒插下层井口(止位环坐沉孔、与顶面齐平)→ 上层落上去套住 → 接缝密封;背侧两定位孔各插 1 销(防呆);左右横拼侧孔插销;最底层坐底座、下放接水托盘;真盆插入盆腔。顶层注水沿中央竖管逐层下流、流经各层浸湿盆底、底座排水口落托盘。本版储水腔不蓄水位(流经浸湿)。

## 改参数(`.scad` 顶部)
| 想改 | 参数 |
|---|---|
| 上下连接有缝 | `conn_recess`(现 1.0,可加大) |

| 背板镂空关/恢复实心 | `back_lattice=false` |
| 背板更省料/更通透 | `lat_ydepth`↑(≥`box_d`≈41%)、`lat_cell`↑/`lat_wall`↓ |
