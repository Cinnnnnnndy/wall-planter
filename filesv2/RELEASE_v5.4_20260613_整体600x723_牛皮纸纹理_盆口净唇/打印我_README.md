# 墙面种植单元 v5.4 — 最终打印包（3×3 墙 + 底座）

> 整面 3×3 + 底座目标尺寸：**宽 600mm × 高 723mm × 进深 236mm**（60cm × 72.3cm）。
> 单元已加宽加高到位、牛皮纸褶皱纹理（v5.6.3）、盆口净唇、背板六角蜂窝减料。本包可直接切片打印。

## 一、整体与单件尺寸（已核验）
- **整面 3×3+底座**：宽 600 × 高 723 × 深 236 mm（= 3×单元宽 + 底座16 + 3×单元高）。
- **单元（planter）**：200 × 235.67 × 199.28 mm（W×H×真实进深），三轴均 ≤240，拓竹 P2S 可打印。
- **稳定底座（base）**：200 × 236 mm（宽×前后进深），≤240。
- 高度接近 240 单件上限（余量约 4.3mm）；若切片实测（盆口朝下倾斜摆位）超 256 仓高，把多余高度改放到底座即可，联系我调。

## 二、可拆真花盆（自备）
- 适配真盆：**上口 Ø131.2 / 底 Ø93.2 / 高 148mm**（标准育苗盆）。
- 盆腔（容器内腔）：口径 134.2 / 底径 96.2 / 深 148，**四周单边间隙 1.5mm**，真盆直接放入落底。
- 自检 potcheck 为空 = 装得下、不干涉。

## 四、打印朝向与设置
- **单元**：盆口朝下贴板、整体倾约 50°（盆轴竖直）——储水腔/落水井/连接孔免支撑（连接缝/盆口朝下时是竖面）。
- **底座**：底面朝下平躺打印；顶面定位销向上、免支撑。
- **连接筒/插销**：平躺小件，可一版多打（见 `build_viewer.py` 注释 / texturize 无关）。
- 建议：0.2mm 层高、PLA/PETG、填充 10–15%（单元偏实心兼配重，约 300–400g/件）、外壁 ≥3 圈。
- 纹理为**向外凸**的表面起伏（不减壁），切片正常即可；切片器可能提示极少量非流形边自动修复（见下）。

## 五、水密性 / 结构（已核验）
- 无纹理几何 `planter_v5.stl`、`base/connector/pin` 均为**闭合流形（完全水密）**。
- **储水盒 + 落水管壁完全密封**：rescheck（横拼孔×储水腔）、latticecheck（背板掏空×储水/落水管）、shaftcheck 全空 → 储水腔不漏、落水管壁不破。
- 纹理版 `planter_v5_tex.stl` 有 ~0.1% 亚毫米边界边，**全部位于前面板表面拼缝**（不在储水/水管壁上）；切片器默认自动修补，不影响水密与打印。
- 逐层水路：上层水→储水腔（浸盆底吸水）→ 溢出经落水管 `connector` 串联落下层 → 最底层经底座中部排水到托盘。

## 六、背板减料
- **六角蜂窝镂空**（back_lattice，对边 18mm，筋 7mm）+ 背面楔形掏空（深 30mm），仅储水腔以上、贴墙隐藏；盆壁/落水管/储水盒/前壳/边框全保留。经背孔通外=无封闭腔。

## 七、组装
1. 每列：底座 → 插第 1 层（底座顶销对底孔）→ 落水管口插 `connector` → 第 2 层 → connector → 第 3 层；每层叠加用 2 根 `pin`（堆叠孔）。
2. 列与列：相邻单元侧面 2 个高度各插 1 根 `pin`（横拼孔）拼齐。
3. 最底层底面排水孔不塞（排到底座/托盘）。

## 八、重新生成（如需改参数）
```
# 几何（需 OpenSCAD）
openscad -o planter_v5.stl -D dev=false -D 'view="unit"' wall_planter_v5.scad
openscad -o base_v5.stl    -D dev=false -D 'view="base"' wall_planter_v5.scad
openscad -o connector_v5.stl -D dev=false -D 'view="connector"' wall_planter_v5.scad
openscad -o pin_v5.stl       -D dev=false -D 'view="pin"' wall_planter_v5.scad
# 纹理（需 numpy+scipy）；改宽度务必同步 texturize.py 顶部 _SIDEG
python3 texturize.py planter_v5.stl planter_v5_tex.stl
# 3D 预览
python3 build_viewer.py planter_v5_tex.stl   # 生成 viewer_tex.html(改名)
```
关键参数：宽→`side_gap`(=29.9)；高→`top_margin`(=22.54)；纹理起伏→`INTENSITY`(=0.9)；整体弯曲→`CURL`(=0.5)；盆口净唇→`MOUTH_CLEAN`(=16)。
