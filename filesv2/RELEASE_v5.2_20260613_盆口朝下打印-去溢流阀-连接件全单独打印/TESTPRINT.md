# 测试打印总单 v5.2 — 先读这一页

> 第一次测试后的大改:**主模型不留任何突出连接件**(原标管/防虹吸帽/出水嘴/锥销/横拼销全删),
> 只留孔与沉孔;突出件(层间连接筒、定位插销)**全部单独打印**。打印朝向改为**盆口朝下**。
> 自检全过:盆腔装得下真盆(potcheck)、井不破腔(shaftcheck)、横拼孔不破腔不破储水盒(tilecheck/rescheck)。

## 1. 打印文件 & 数量

| 件 | 文件 | 数量 | 说明 |
|---|---|---|---|
| **单元**(所有单元完全一致) | `planter_v5.stl` | 测试先 1,再 2 | 主模型,无突出件 |
| **层间连接筒** | `connector_v5.stl` | = 堆叠缝数(2 层叠=1) | 插上下井口,密封下水接缝 |
| **定位插销**(通用) | `pin_v5.stl` | 每堆叠缝 2 + 每横拼缝 2 | 堆叠/横拼共用同一种销 |
| **稳定底座** | `base_v5.stl` | 每列 1(垫最底层) | 顶面带向上定位销 + 中部排水口 |

## 2. 摆放朝向(关键)
- **单元:盆口朝下贴板**(盆轴转竖直,箱体后仰约 50°,如 `v52_printpose.png`)。
  - 这样**储水腔、落水井都不需要支撑**;盆腔是竖直锥(口朝下),自支撑。
  - 切片器里用"按面摆放/Place on face"选盆口端面,或绕 X 轴转到盆轴竖直。
- **连接筒 / 插销 / 底座**:平躺或竖放都行,体积小、基本免支撑(连接筒竖放打,内孔自支撑)。

## 3. 切片参数(Bambu Studio 起点)
- 层高 0.20(纹理版需 ≤0.2),墙 2 周,顶/底各 3 层;
- **储水区加厚**:对单元用高度范围修改器,把储水腔所在高度段(沿打印 Z 的最低 ~35mm 实体区)墙加到 4、填充 15%,防渗;
- 填充 6–8% gyroid;
- 支撑:盆口朝下时基本免支撑;若切片预览仍有零星悬垂(盆腔上沿/井口),开**树状+仅接触面**少量;
- 连接筒/插销:精度优先,层高 0.12–0.16,壁全实心。

## 4. 装配
1. **层间**:把 `connector_v5.stl` 插进下层单元**井口(顶面)**——止位环坐进井口沉孔、与顶面齐平;上半露出。再把上层单元落上去,上层井底套住连接筒上半 → 接缝密封,水从上层经筒内落到下层。
2. **上下定位/防转**:每条堆叠缝在背侧两个定位孔各插 1 根 `pin_v5.stl`(孔位非对称,防呆,装反对不上)。
3. **左右横拼**:相邻两单元侧面孔对齐,插 `pin_v5.stl`(两个高度各 1 根)。
4. **最底层**:坐进 `base_v5.stl`(底座顶面销插入单元底孔);底座中部是排水口,**下方放接水托盘**。
5. 真花盆插入各层盆腔(到底、不晃,验 1.5mm 间隙)。

## 5. 浇水(串联下水,已去溢流阀)
- 从**顶层落水井口注水**或逐盆浇水;水沿中央竖管经各层连接筒**逐层往下流**,流经每层储水腔时浸湿盆底,多余的下渗到底层,经底座排水口落进**托盘**。
- 接缝由连接筒密封,**直接堆叠不会从缝里漏水**。
- 注:本版**储水腔不再蓄水位**(去了溢流阀),是"流经浸湿"而非"泡盆"。若想恢复存水浸盆,告诉我,我把连接筒加高做成"无帽溢流管"版本。

## 6. 这次重点验证
- [ ] 盆口朝下打印:储水腔/井**真的不用支撑**、表面 OK;
- [ ] 连接筒插上下井口的**松紧**(现配合单边 ~0.4mm,偏松/偏紧告诉我调 `conn_fit`);
- [ ] 插销与孔松紧(`pin_clear`/`join_clear`);
- [ ] 注水:逐层下流顺畅、接缝不漏、底层排进托盘;
- [ ] 真盆配合(1.5mm)。

## 7. 出问题→改哪里(改 `.scad` 顶部参数后重导)
| 现象 | 调整 |
|---|---|
| 连接筒太松/太紧 | `conn_fit`(经 `shaft_d-0.8` 派生)或直接调 `shaft_d` 沉孔 |
| 插销太松/太紧 | `pin_clear`(销径)/`join_clear`(孔径) |
| 真盆太紧/太松 | `fit_clear`(现 1.5) |
| 储水腔渗水 | 储水区切片加墙;确认横拼孔仍在储水以上(`rescheck` 应空) |
| 想要存水浸盆 | 找我加"无帽溢流管"连接件 |
