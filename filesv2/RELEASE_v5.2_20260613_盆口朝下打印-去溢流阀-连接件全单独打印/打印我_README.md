- **本版更新内容(第一次测试打印后的大改)**:
  1. **打印朝向改"盆口朝下贴板"**(盆轴竖直、整体倾 ~50°)→ 储水腔/落水井**免支撑**;

  5. 所有单元**完全一致**(横拼改双侧孔,删掉了旧的"最右列变体");底座顶面改向上销+中部排水口。

## 怎么打(必看)
- **单元:盆口朝下贴板**(盆轴转竖直,箱体后仰约 50°,见 `v52_printpose.png`)。切片器用"按面摆放"选盆口端面,或绕 X 轴转到盆轴竖直。这样储水腔/落水井免支撑。
- **储水区加厚**:用高度范围修改器把储水腔那段(沿打印 Z 最低约 35mm 实体)墙加到 4、填充 15% 防渗;其余 2 周 + 6–8% gyroid。
- **连接筒/插销**:小件,精度优先(层高 0.12–0.16、全实心);连接筒竖放打,内孔自支撑。
- **底座**:掏空面朝下,免支撑。

## 怎么装
1. 连接筒插进下层单元**井口(顶面)**,止位环与顶面齐平;上层落上去套住 → 接缝密封。
2. 背侧两个定位孔各插 1 根插销(防呆,装反对不上);左右横拼侧孔对齐插销。
3. 最底层坐进底座;底座中部排水口下方放**接水托盘**。
4. 真花盆插入盆腔。

## 浇水(串联下水)
从顶层注水 → 水沿中央竖管经连接筒逐层下流、流经各层浸湿盆底 → 多余的从底座排水口落进托盘。接缝由连接筒密封,直叠不漏。
> 本版储水腔**不蓄水位**(已去溢流阀),是"流经浸湿"。想恢复"泡盆存水",找作者加"无帽溢流管"连接件版本。
