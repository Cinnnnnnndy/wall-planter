# 测试打印总单(v5.1.3) — 先读这一页

> 详细原理见 `PRINT.md`;本页是"照着做就能打"的精简版。所有尺寸已核验:三轴 ≤240(拓竹 P2S 可打),
> 盆腔按真盆 148/Ø131.2/Ø93.2 + 单边 1.5mm 间隙,`potcheck`/`shaftcheck` 自检通过。

## 1. 这次测试要验证什么
1. 真花盆放得进、坐到底、不晃(1.5mm 间隙合不合适);
2. 储水盒不漏、水位浸到盆底(土壤吸水);
3. 超水位经落水井**逐层往下淌**、最底层橡胶塞挡住不滴地;
4. 上下堆叠 / 左右横拼的销孔配合;
5. **支撑能不能顺利拆掉**(尤其盆腔内、落水井);
6. 底座稳不稳(满载不前倾)。

`planter_v5_norightpeg.stl`=无右侧横拼销版(整面墙最右一列用,本次测试用不到)。

## 3. 摆放朝向(关键!)
- **单元:箱底朝下竖立**(=装到墙上的姿态,也是 STL 原生姿态,导入后**不要旋转**)。
  - 原因:落水井 Ø23 细长孔只有竖直时才**不需要支撑**;平躺会把它变横隧道、支撑困死还堵水路。
- **底座:掏空面朝下平放**(免支撑)。

## 4. 切片参数(Bambu Studio 起点)

**全局**
- 喷嘴 0.4mm,层高 **0.20mm**;
- 墙/周数 **2**,顶/底各 **3** 层;
- 填充 **6–8% gyroid**;
- 材料:室内 PLA;接触水/见光 PETG 更稳。

**储水区加厚(高度范围修改器,Z 0–35mm)**:墙 **4**、底 **5** 层、填充 **15%** —— 防漏关键。

**支撑(单元)**
- 类型 **树状(tree)**,**仅接触面(support interface)**,密度 8–10%,顶部接触距离 0.2mm(好剥);
- **关掉"仅在床面生成(on build plate only)"**——否则盆腔上壁/储水顶得不到支撑;
- **底面销/出水嘴朝下 → 开 raft**;瘦高件 **加 brim** 防倒。

**用量预估(切片为准)**:单元 ≈400g 件身 + ≈100–150g 支撑/raft ≈ **0.5–0.55kg、约 10–16h**;底座 ≈140g、约 4–6h。

## 5. 拆支撑(打完先做这步)
- **盆腔内**:从盆口(Ø134 大开口)伸手/镊子把上侧内壁的支撑清干净 —— **残料会顶住真盆插不到底**;
- 斜盆悬出段底面支撑:从外面掰掉;
- 落水井、立管:竖直,**本就无支撑**,确认通透即可;
- 底面 raft/brim:整片撕掉;储水腔内若有少量支撑**可不清**(藏在水箱、水绕流)。

## 6. 装配 & 测试
1. 最底层单元出水口塞**橡胶塞**;其余层不塞;
2. 单元坐进**底座**(底销落入底座销孔);
3. 真花盆插入盆腔,确认到底、不晃(验 1.5mm);
4. (第二轮)第二件叠上去:锥销自对中、出水短嘴入下层井口;需要时左右横拼;
5. **注水测试**:从顶层落水井口注水,逐项看 ——
   - [ ] 储水层存住、四壁不渗;
   - [ ] 水位浸到盆底、土壤能吸上水;
   - [ ] 超水位经落水井**垂直落进下一层**、不沿叠合缝外漏;
   - [ ] 最底层被橡胶塞挡住、不滴地;
   - [ ] 停注水后储水**不被虹吸抽空**(防虹吸帽);
6. **稳定性**:满载(湿土+植株)后轻推单元上沿,底座兜得住不前倾。

## 7. 出问题→改哪里(改 `.scad` 顶部参数后重导 STL)
| 现象 | 调整 |
|---|---|
| 真盆太紧/太松 | `fit_clear`(现 1.5mm 单边) |
| 销插不进/太松 | `peg_clear`(现 0.3) |
| 储水段渗水 | 储水区加墙周数;或换 PETG |
| 吸水不足 | 加大 `immerse`(需 < `lens_open`) |
| 仍前倾 | 加大 `base_reach_f`(注意 box_d+前+后 ≤240) |

> 反馈测试结果(尤其配合松紧、是否渗水、支撑好不好拆)给我,我据此微调参数再出下一版。
