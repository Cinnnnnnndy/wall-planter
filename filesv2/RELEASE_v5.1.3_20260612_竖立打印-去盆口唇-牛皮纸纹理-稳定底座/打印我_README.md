## 怎么打(必看)
- **单元:箱底朝下竖立,导入后不要旋转**(STL 原生姿态即正确朝向)。
- 切片:层高 0.20、2 周壁、6–8% gyroid;**储水区 Z0–35mm 高度修改器加到 4 周/15% 防漏**。
- 支撑:树状 + 仅接触面,密度 8–10%,**关掉"仅床面"**;底面销/嘴朝下 → 开 **raft**;瘦高件加 **brim**。
- 拆支撑:**盆腔内残料务必从盆口清干净**(否则顶住真盆插不到底);落水井竖直无支撑。
- 底座:掏空面朝下平放,免支撑。
