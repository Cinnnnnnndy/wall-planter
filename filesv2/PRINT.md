# 打印指南 — 墙面种植单元 v5.1.1

对标打印机 **拓竹 P2S**(有效 256³,本设计按 ≤240mm/轴)。下列参数为推荐起点,**最终以切片器预览为准**。

## 1. 打印哪几件

| 件 | 文件 | 首测数量 | 完整测试 | 说明 |
|---|---|---|---|---|
| 种植单元 | `planter_v5.stl` | 1 | **2** | 逐层落水 + 上下堆叠接口需 ≥2 件才能验 |
| 稳定底座 | `base_v5.stl` | 1 | 1 | 每"一列"只需 1 个,垫最底层 |

> **外观版**:想要牛皮纸褶皱质感,用 `planter_v5_tex.stl` 代替 `planter_v5.stl`(配合/堆叠/水路完全一致,只是外壳带纹理)。该件约 56MB、110 万面,**切片器开默认"修复/自动修补"**(Bambu Studio 默认即开)以处理位移网格的极少量瑕疵边;层高建议 ≤0.2mm 才看得出折痕。功能测试可先用光滑版,定稿外观再换纹理版。

**非打印配件(先备好)**
- **锥形橡胶/硅胶塞 ×1**,Ø8–11(配底面 Ø11→Ø8 锥孔):只塞在**最底层**单元出水口。
- **真可拆花盆**:高 148 / 上口 Ø131.2 / 底 Ø93.2(验 1.5mm 间隙能否插到底)。

> 省料摸底:**先打 1 单元 + 1 底座**,过了"配合/储水/浸盆/塞水/打印质量"再补第 2 单元验堆叠。

## 1.5 3×3 整墙方案(52×73cm 空间,已核验)

| 项 | 数值 |
|---|---|
| 阵列宽 | 3×170.2 = **510.6mm**(最右列保留侧销则 +6 → 516.6) |
| 阵列高 | 3×228.5 + 底座16 = **701.6mm** |
| 空间 | 520 × 730mm → **宽余量 9.4mm(无销)/3.4mm(带销),高余量 28.4mm** ✅ |

- **打印清单**:单元 ×9(其中**最右一列 3 件**建议用 `-D 'tile_pegs=false'` 导出的无侧销版,宽度余量回到 9.4mm)+ 底座 ×3 + 橡胶塞 ×3(每列最底层 1 个)+ 真花盆 ×9。
- 预览:`view="wall33"`(`v5_wall33.png`);尺寸自检 echo 会直接报"放得下? true/false"。
- 注意:满载(湿土+水+植株)单件 ≈2.7kg,整墙 **≈25kg** —— 放置面要能承重;3 列横拼互锁后整体稳定性优于单列(单列临界前倾角 ≈18°@3层)。
- 顶部余量 28mm:够从最顶层落水井口用细嘴壶注水;空间更紧可改为直接浇顶层盆。
- 进深:单元真实进深 ≈199mm,底座 236mm —— 此空间需有 **≥240mm** 进深。

## 2. 外形尺寸(核对幅面)

| 件 | W | 进深 | 高 | 三轴 ≤240 |
|---|---|---|---|---|
| 单元 | 170.2 | ≈199(含盆底后伸) | 228.5 | ✅ |
| 底座 | 170.2 | 236 | 16 | ✅ |

底座进深 236 已贴近上限,**摆正打印**即可;若床略小可沿对角线摆放。

## 3. 摆放朝向 / 支撑

- **单元**:**背面朝下平躺、盆口朝上**。这样背板是床面、斜盆开口朝上,大部分面自支撑。
  - **切片预览重点看这几处悬垂,必要时开支撑(建议树状/仅接触面)**:
    - 斜盆锥腔的**下侧壁**(约 40° 斜面,接近临界);
    - **落水井顶口**与井壁(竖直内孔,通常 OK);
    - **盆口挡土唇/滴水线**法兰下缘;
    - **底面出水短嘴**与**底销**(朝下小凸起,可不支撑或加少量)。
  - 顶/底叠合面要平整 —— 关掉"底面喇叭口/象脚",必要时加大床面附着但保证首层不溢边。
- **底座**:掏空面朝下平放,外圈+十字肋自支撑,**免支撑**;顶面销孔朝上。

## 4. 切片参数(起点)

| 项 | 推荐 | 备注 |
|---|---|---|
| 层高 | 0.2–0.28mm | 功能件,粗层更快 |
| 壁/周数 | ≥3 周(≈1.2mm) | 设计壁厚 3mm,留足周数保证储水段不渗 |
| 顶/底层 | 4–5 层 | 储水盒底/顶要够密实防渗 |
| 填充 | **10–15%** | 单元为实心建模,用料几乎全看填充;加了底座后压舱非必需,可放心调低 |
| 填充图案 | gyroid / cubic | 兼顾强度与轻量 |
| 出料/缩放补偿 | 先打 **配合测试**再定 | 见下 §5 |

> 实测用量(切片为准,仅估):单元 ≈300–400g / 8–14h;底座 ≈140g / 4–6h。

## 4.5 材料用量测算与省料策略(已用模型面积/体积解析验证)

单元模型体积 1688cc、表面积 2804cm²。按"等效壳厚 1.1mm(3 周壁+顶底皮)+ 填充"估打印质量:

| 设置 | 单件估重 | 3×3 九件 |
|---|---|---|
| 3 周壁 + 8% gyroid | **≈519g** | ≈4.7kg |
| 3 周壁 + 12% | ≈588g | ≈5.3kg |
| 3 周壁 + 15% | ≈639g | ≈5.8kg |
| **分区优化(推荐,见下)** | **≈450–480g** | **≈4.1–4.3kg** |

**为什么不做 CAD 掏空**(已解析验证):掏空省的是"填充料"(8% 时每 cc 只省 0.08cc 塑料),但新开的袋壁/肋/袋顶要按**实心壳**(~1.1mm)打。背部格栅袋逐格收支:26mm 格**净亏 5g/格**、46mm 格亏 5g;8% 填充下要 **>75mm 的格宽才开始净省**,而那种跨度内部架桥不可靠、再加肋又回到亏料。结论:**实心建模 + 稀疏填充已是 FDM 最优**,模型不掏。

**推荐省料组合(切片器分区/修改器实现)**:
1. **下部储水区(z<35mm)**:4 周壁 + 底 5 层 —— 防渗水,这里不省;
2. **上部主体(z>35mm)**:**2 周壁** + 顶底 3 层 —— 大头在这,省 ~65–70g;
3. **填充 8% gyroid** 全局(底座有支承肋,8% 足够);
4. 合计 ≈**450–480g/件**,比默认 12% 设置省 ~110–140g/件、九件省 **≈1.1kg**。
5. 可选再省:0.6mm 喷嘴 2 周壁(=1.2mm,强度同 3×0.4)且提速 ~40%。

**纹理版差异**:`planter_v5_tex.stl` 体积 1739cc(+51cc 外凸褶皱,全在表皮层)→ 约 **+40–60g/件**。
**为什么蜂窝/网格/薄壳也不省**(已解析验证,2 周壁/6% 下):模型里留"空气"只费 0.06cc 塑料/cc(填充),而每 mm² 新增面(蜂窝壁/孔壁/内壳)要按 ~0.85mm 实心打。实算:蜂窝面板替代 50mm 厚区 **费 1.2~3.1×**;打穿孔要 **Ø>40mm 才回本**(Ø60 省 6.7g、Ø80 省 17.8g,但放不下几个且破坏正面纹理/结构);整箱掏成 2mm 封闭薄壳**净亏 38g**。**切片器的 6% gyroid 本身就是最优蜂窝**(自承重、无需围壁),手工格栅打不过它。

**几何微调不值得**:缩 `mouth_ext`/`floor_t` 单件只省 <10g 还动配合;缩 `box_d` 66→58 可省 ~50g 但储水量 -13%、需重验稳定性 —— 如需更轻可提,默认不动。

## 4.6 省料切片配方(Bambu Studio,不改几何,目标 ≈390–410g/件)

> 已验证:本件用料由"壳(表面积×蒙皮)"主导而非填充,故省料靠**减周数/降填充**,几何不动。
> 关键约束:**储水区(z 0–35mm)必须保持密实防渗**,用"高度范围修改器"单独加厚。

**全局设置**
- 层高 **0.20mm**(>0.24 会看不清牛皮纸折痕,纹理版尤其);
- 墙/周数 **2**;顶层 **3**、底层 **3**;
- 填充 **6% gyroid**(gyroid 各向同性、无需支撑自承);
- 支撑:默认关;切片预览检查盆锥下壁/落水井顶口,**仅必要处开树状支撑**;
- 朝向:**背面朝下平躺、盆口朝上**。

**高度范围修改器(关键一步)** — 选中单元,加 Height range modifier,范围 **Z 0–35mm**,在该范围内覆盖:
- 墙/周数 **4**;底层 **5**;填充 **15%**。
- 作用:储水盒四壁+底密实防渗,其余部分照全局的轻量设置走。

**预期用量**:单件 ≈**390–410g**(PLA;PETG×1.27 ≈ 500g)。3×3 九件 ≈ **3.5–3.7kg**,比默认(3 周/12%≈588g×9=5.3kg)省 **≈1.6kg**。

**可选再省/提速**
- 0.6mm 喷嘴:2 周=1.2mm(强度≈3×0.4mm),时间 −~40%,克数基本持平;
- 填充降到 **5%**:再省 ~25g/件(底座有承重肋,单元上部受力小,可行);
- 储水若改用"内胆塑料盒"另放,可把储水区也降到 2 周(本设计默认靠壁防渗,故不建议)。

**底座**:全局 3 周 + 8%(它要承整列重量,别低于此);约 140g。
**纹理版**:`planter_v5_tex.stl` 同上设置 +40–60g/件(表皮褶皱)。

## 5. 配合(最影响成败,先验后批量)

- **花盆插配**:设计单边间隙 1.5mm。若实测偏紧/偏松,改 `.scad` 顶部 `fit_clear` 重导出,**别只靠切片缩放**。
- **堆叠/横拼销**:间隙 `peg_clear=0.3`。偏紧 → 加大到 0.4–0.5;偏松 → 减小。改后重导出。
- 建议先单独打一个**1cm 高的盆口段 + 一对销孔**做配合校验(可在切片器里只保留底部薄片),再决定整件参数。

## 6. 材料

- **室内**:PLA 即可。
- **接触水 / 见光 / 户外**:建议 **PETG**(耐水、抗 UV、韧)。储水段尤其建议 PETG 并适当提高壁周数。
- 浅色更易看清积藻/水位;深色更接近实物观感。

## 7. 装配 & 测试清单

1. 最底层单元出水口塞**橡胶塞**;其余层不塞。
2. 最底层坐进**底座**(底销落入底座销孔)。
3. 逐层往上叠(锥销自对中;出水短嘴入下层井口);需要时左右横拼(右销入左孔)。
4. 真花盆插入各层盆腔,确认插到底、不晃。
5. **注水测试**:从最顶层落水井口注水 → 看
   - [ ] 储水层存住、不从壁缝渗;
   - [ ] 水位浸到盆底、土壤能吸上水(浸盆窗 5mm);
   - [ ] 超水位经水注溢流、**垂直落入下一层**井口,不沿叠合缝外漏;
   - [ ] 逐层下淌,最底层被橡胶塞挡住、不滴地;
   - [ ] 防虹吸帽:停止注水后储水**不被抽空**。
6. **稳定性**:满载(湿土+植株)后轻推单元上沿,确认底座兜得住、不前倾。

## 8. 出问题时改哪里(.scad 顶部参数)

| 现象 | 调整 |
|---|---|
| 花盆太紧/太松 | `fit_clear`(单边间隙) |
| 销插不进/太松 | `peg_clear` |
| 储水段渗水 | 加壁周数 + `wall` / 顶底层数;或换 PETG |
| 吸水不足 | 加大 `immerse`(浸盆深,需 < `lens_open`) |
| 仍嫌前倾 | 加大 `base_reach_f`(注意 box_d+前+后 ≤240) |
| 落水没对准下层 | 检查 `shaft_x/shaft_y`(改后重跑 `shaftcheck` 应为空) |

> 改任意几何后,务必重渲 `view="potcheck"` 与 `view="shaftcheck"`(均应输出 "object is empty"),再 `-D dev=false` 导 STL。
