# SPEC — 我的设计目标(改模型前先读这个)

## 1. 打印机(必填,决定是否分块)
- 有效打印尺寸 X × Y × Z = **256 × 256 × 256** mm(拓竹 Bambu Lab P2S)
- 机型/喷嘴:**P2S / 0.4mm**
- 材料:待定(室内建议 PLA,室外建议 PETG/ASA)

## 2. 安装方式(三选一)
- [ ] 贴墙挂(需挂耳/锁孔或法式斜挂)
- [ ] 独立隔断(需底座脚,可能做双面花盆)
- [x] **仅堆叠**(无墙面安装件;但保留燕尾+定位销,单元间四向拼接)

## 3. 花盆形式
- 用户**自带实物锥形盆**,模块只做**承接斜插的盆座(socket)**,盆可单独取放/换盆。
  盆座按实测盆型 + 间隙做成锥台腔,不另打印花盆。

## 4. 防水要求(二选一)
- [x] **仅逐层淌水**,底层加堵塞别滴地上(当前默认)
- [ ] 真·密封储水

## 已建模机制(planter_v2.stl, v4 斜切洁净开口, 2026-06-09)
- **开口沿花盆角度斜切**: 开口面 ⟂ 花盆轴线(=沿盆倾角), 是完整正圆、不被腔壁遮挡, 盆口平齐坐入。修复了 v3 在竖直面开圆被斜腔下壁遮挡的问题。
- **外壳=省料楔形**(非方盒): 侧剖面贴合花盆斜切, 顶/前随盆斜面、后矮竖壁、平底储水, 沿宽度拉伸→左右面平整可横拼。
- 腔体: 圆台(宽端 134.2 朝开口 / 窄端 96.2 在后下),深 150,**倾角 55°(更竖立)**,单边间隙 1.5mm(直径 +3)。
- 灌溉: 盆底排水 → 最低处储水沟(深 12)→ **溢流标管(水位 8mm)** 超水位穿底滴下层;底层标管口塞橡胶塞(⌀9)。
- 透气: 开口后上沿 3 个 ⌀5 透气孔(穿顶斜面进腔)。
- 顶后沿半圆缺口(⌀26)。
- 拼接(仅堆叠/非承重): 顶销(立在后顶斜面)+底孔、右销+左孔, 销径 7, 间隙 0.3。
- 校验: CGAL Volumes=2(单一实体, 无封闭空腔), 腔体不穿底/不穿背, 水路连通。
- 待优化: 顶面是斜的, 上下堆叠靠斜面销+侧销定位(非全平面贴合); 如需更稳的堆叠面可后续加平台接口。

## 备注
- 落盆间隙: SPEC 表里 pot_fit=2.0,但本次按 PROMPT 的「单边 1.5(直径 +3)」建模。若实测偏松/偏紧,改 `fit_clear` 即可。
- 待用户实测花盆后可调:若盆口有外翻边/卡边,可加「开口挡土前唇」防下滑;倾角可在 25–30° 间微调改变进深。
- 拼接当前用定位销(非承重燕尾);若横排需承重再换燕尾。
